# 👻HuTao Theme for Eclipse Animator

👋Hey, It's just a perfect theme for Eclipse Animator in roblox studio!

# 📝How to download it?

1) Download  HuTaoTheme.txt
2) Go to Roblox Studio to any place
3) Open  Eclipse Animator
4) Go to  Settings > Customization  and click on "Load a theme from JSON"
5) Put text from  file here and click load
6) Save your preset in  Presets > Your Presets  and save your theme
